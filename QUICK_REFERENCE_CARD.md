# InvestIQ - Quick Reference Card

## 🎯 30-Second Pitch
AI-powered financial literacy platform with adaptive learning, real-time market data, and voice tutoring - deployed globally on Cloudflare Edge with sub-100ms latency.

---

## 🏗️ Tech Stack (Quick Glance)

### Frontend
- **Next.js 16** (TypeScript) - Static export for edge deployment
- **Tailwind CSS** - Utility-first styling
- **Framer Motion** - Smooth animations
- **Recharts** - Interactive financial charts

### Backend
- **Python FastAPI** - Async REST API
- **Railway** - Auto-scaling PaaS
- **Cloudflare Pages** - Edge hosting (300+ PoPs)
- **Cloudflare D1** - Distributed SQLite
